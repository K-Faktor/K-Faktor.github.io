# CoD4 Tools

Небольшой набор браузерных инструментов для Call of Duty 4 / Promod, всё на одной странице. Ничего устанавливать и настраивать не нужно — открой `index.html`, и всё работает. Всё выполняется локально в браузере; ни один конфиг никуда не загружается.

Живёт на <https://k-faktor.github.io>.

## Вкладки

### проверка конфига

Вставь конфиг или загрузи файл `.cfg` — инструмент отметит строки, которые лиги и матчевые серверы обычно запрещают.

- Запрещённые имена DVAR'ов помечаются красным, запрещённое содержимое в биндах и значениях — оранжевым. Список имён покрывает 318 известных читерских и читерско-менюшных имён.
- 33 защищённых клиентских DVAR'а никогда не помечаются, даже если в имени встречается запрещённое слово.
- Помеченные строки подсвечиваются прямо в тексте, рядом — номера строк.
- У каждой находки есть **«Перейти к строке»** и **«Удалить строку»**.
- **«Загрузить .cfg»** открывает локальный файл, **«Копировать»** кладёт конфиг в буфер обмена, **«Скачать»** сохраняет его как `config_mp.cfg`.

### rcon-команды

Справочник по Promod rcon с кнопкой копирования для каждой команды: вход и серверные команды, режимы promod с синтаксисом и примерами, игровые режимы, управление матчем и все 21 карта.

### двары

Все 1196 дваров CoD4, отсортированы по имени и ищутся по имени или описанию. Для каждого показаны описание, тип, значение по умолчанию, допустимый диапазон и, где есть именованные настройки, — что означает каждое число.

### цвета килфида

Выбери два цвета команд и получи строку конфига для них.

- Палитра цветов, значение `r g b a` и hex-поле для каждой команды — меняешь любое из них, остальные подстраиваются.
- Можно вставить значения, которые уже есть в твоём конфиге, чтобы увидеть, какому цвету они соответствуют.
- Живой предпросмотр показывает, как имена выглядят в килфиде.
- Результат — строка бинда, которая переприменяет цвета на каждое нажатие клавиши, что помогает на серверах, где их сбрасывают:


  ```
  bind W "+forward; g_TeamColor_Allies 0.498 0.655 1 1; g_TeamColor_Axis 1 0.541 0.361 1"
  ```

  Клавишу и действие можно менять.

### генератор табло

Собери своё табло и посмотри его до входа в игру.

- Имена команд, цвета строк, размеры и отображение пинга — всё в одном месте.
- Предпросмотр обновляется по мере ввода и следует правилам вёрстки самой игры.
- Лестница пинга показывает, во что превращается каждый диапазон пинга: сколько полосок и какой цвет — для текущих значений.
- Вывод идёт тремя блоками, у каждого своя кнопка копирования: строка `bind TAB` для значений, которые мод сбрасывает при каждой смене команды, строки `seta` для табло и графика пинга и строки `seta` для имён и цветов команд.

### ЧаВо

Ответы на вопросы, которые постоянно возникают вокруг `config_mp.cfg`, с поиском по вопросу, ответу или команде. Начинается с того, что устанавливать для дисковой версии, версии из Steam и FPS Challenge; в ответах про настройки даются и строка конфига, и консольная команда — с кнопкой копирования у каждой.
